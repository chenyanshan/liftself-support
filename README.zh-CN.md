# LiftSelf — 离线力量训练日志

**为自己而练。**

LiftSelf 是 HIHIHIAI Studio 开发的 iOS 和 Android 力量训练日志，以本地存储为主，无广告，无需注册 LiftSelf 账号。核心记录可离线使用，支持兼容的 Strong / Hevy 训练历史 CSV，Pro 为可选一次性买断，无订阅。

本仓库由开发者维护，提供 [LiftSelf](https://hihihiai.com/zh/liftself) 的使用说明与反馈入口。

LiftSelf 正在为 iOS 和 Android 准备发布，暂未开放下载。Apple Watch 和 Wear OS 伴侣仍在准备。获取最新状态请查看[官网](https://hihihiai.com/zh/liftself#download)。

- 免费：无限训练记录、历史与模板，7 个自建动作，30 天图表，导入导出及完整备份。
- Pro：无限自建动作和 12 周／一年／全历史分析，一次性买断。
- 计划美区价格：首次公开上架后 30 天内 $14.90，之后 $19.90，以商店当地结算价格为准。这不是每位用户安装后的 30 天试用。
- 存储：本机为主；支持的 Apple 版本可选私人 iCloud 同步（默认开启，可关闭）。同步不等于完整备份。Android 无 iCloud / Google Drive 同步，使用文件导入导出。
- 迁移：先保留原 CSV，再在“设置 → 我的数据 → 备份与恢复 → 导入数据”预览日期、动作类型、单位与时区，确认后检查历史。CSV 不迁移原账号、完整模板库或所有附件。导入后可选择一次训练，编辑并保存为模板。
- 社交：没有动态、关注、点赞和排行榜；可自行选择分享训练图片。
